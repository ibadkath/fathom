You can create an OpenAI API key here:

[OpenAI API Keys](https://platform.openai.com/api-keys)

Steps:

1. Sign in or create an OpenAI account.
2. Open **API keys**.
3. Click **Create new secret key**.
4. Copy it immediately. OpenAI only shows the full key once.
5. Add it to `.env.local`:

```env
OPENAI_API_KEY="sk-your-key-here"
OPENAI_MODEL="gpt-4o-mini"
```

Then restart Next.js:

```powershell
npm run dev
```

Keep the key private. Never commit `.env.local` or expose the key in client-side code.
