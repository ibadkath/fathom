# 3. Prisma database

Your `schema.prisma` can be relatively small.

```
User
 │
 └── Meeting
       │
       ├── TranscriptSegment
       ├── ActionItem
       ├── Highlight
       └── MeetingSummary
```

### Meeting

```
model Meeting {
  id           String   @id @default(cuid())
  title        String
  duration     Int
  participants Int
  startedAt    DateTime
  audioUrl     String?

  transcript   TranscriptSegment[]
  summary      MeetingSummary?
  actionItems  ActionItem[]
  highlights   Highlight[]

  createdAt    DateTime @default(now())
}
```

### Transcript

```
model TranscriptSegment {
  id        String @id @default(cuid())
  meetingId String
  speaker   String
  text      String
  startTime Float
  endTime   Float

  meeting Meeting @relation(fields: [meetingId], references: [id])
}
```

### Summary

```
model MeetingSummary {
  id         String @id @default(cuid())
  meetingId  String @unique
  summary    String
  topics     Json
  decisions  Json

  meeting Meeting @relation(fields: [meetingId], references: [id])
}
```

### Action items

```
model ActionItem {
  id        String  @id @default(cuid())
  meetingId String
  task      String
  owner     String?
  deadline  String?
  completed Boolean @default(false)

  meeting Meeting @relation(fields: [meetingId], references: [id])
}
```

### Highlights

```
model Highlight {
  id        String @id @default(cuid())
  meetingId String
  startTime Float
  endTime   Float
  note      String

  meeting Meeting @relation(fields: [meetingId], references: [id])
}
```

You can add `Share` later.
